# Abdullah Shah | Web Developer Portfolio

A hand-coded portfolio built with plain HTML, CSS and JavaScript. No frameworks, no build step, so what you see in this repo is exactly what runs in the browser.

**Live site:** https://abdullah-ops-del.github.io

## About

I'm Abdullah, a web developer with about a year and a half of hands-on learning and building. I work with HTML, CSS, JavaScript and WordPress, and I care about sites that load fast, look sharp on a phone and are easy to keep updated.

My earlier work isn't with me right now, so this repo contains three working demo projects you can open and try yourself. The full source for each one is here.

## What's inside the site

- **Interactive terminal** in the hero. Type `help` to see commands such as `skills`, `projects`, `contact` and `theme`.
- **Neon rain background** drawn on a canvas, a cursor glow, and 3D tilt on cards.
- **Responsive layout** that works from phone to widescreen.
- **Accessibility basics:** visible keyboard focus, labelled form fields, and reduced motion respected.

## Projects

| Project | What it does | Live demo |
|---|---|---|
| **Pip Journal** | A trade journal. Log trades in R and see win rate, average R and an equity curve update instantly. Saves to the browser. | [Open](https://abdullah-ops-del.github.io/projects/pip-journal/) |
| **Ember & Oak Coffee** (concept) | A café site with a filterable menu, an order with a live total, and a table-booking form with validation. | [Open](https://abdullah-ops-del.github.io/projects/ember-oak/) |
| **Throttle Club** (concept) | A bike club page with a live countdown to the next ride, route filters, one-tap RSVP and a rider badge maker. | [Open](https://abdullah-ops-del.github.io/projects/throttle-club/) |

Ember & Oak and Throttle Club are concept builds made to show how I work. They are not real client projects, and nothing you enter in them is sent anywhere.

## Tech

- HTML5, CSS3 (custom properties, grid, flexbox)
- Vanilla JavaScript (canvas, IntersectionObserver, localStorage)
- SVG for the Pip Journal chart
- Google Fonts: Unbounded and Manrope
- Hosted on GitHub Pages

1. Download or clone this repo.
2. Open `index.html` in your browser.

No install needed. An internet connection is only used to load the fonts.
